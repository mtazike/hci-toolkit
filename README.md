# HCI Toolkit

Tools for planning and reviewing HCI research.

## Contents

| Tool | What it does |
|---|---|
| [`hci-research-quality-gate`](hci-research-quality-gate/) | A Claude Skill that checks a study design before IRB and data collection (Gate 1), and a manuscript, poster or resubmission before submission (Gate 2). Output is a short guide: what to include in each part of the study or paper, how required it is (Must / Should / Optional), and the most accepted HCI solution. |
